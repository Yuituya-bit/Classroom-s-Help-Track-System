# Classroom's Help & Track System
実験を含む授業における進捗及び質問を講師が把握するための確認システム

## 概要
学生が持つスマートフォン等のクライアントからサーバーへ情報を送り、サーバ上にあるテキストファイルに情報を書き込む。それを基に講師が持つクライアント端末へ情報を送ることで講師が進捗及び学生の呼び出しを把握するシステム。

## ファイル別システム
- 認証系システム
　- index.php/:ログインするのが学生なのか講師なのかを選択
  - password.php/:講師がパスワードを入力する画面
  - log_in_check.php/:ログイン履歴を確認し、URLへの入力による直接のアクセスを遮断
 
- 講師向けシステム
　- option3.php/:実験タイトルや進捗の選択肢を入力する画面、完了後に授業開始
  - main3.php/:すべての班の進捗及び呼び出しが見られる画面5秒ごとに自動更新が入る
 
- 学生向けシステム
　- student3.php/:自分の班の進捗を報告するための画面
  - signal.php/:質問や困ったことがあった際に簡単な要件を添えて先生を呼びだす画面

## 言語
サーバ：Apache
使用言語：PHP, HTML
